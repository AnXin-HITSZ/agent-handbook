# Prompts

收录围绕具体任务、可复制到对话中使用的指令。每篇应说明适用场景、所需输入、指令正文和使用边界；不收录只有口号、缺乏明确输出的内容。

## 已有资产

- [引导式代码学习](learning/guided-code-learning.md)：通过目标确认、代码导航、小步提问和理解验证来学习已有代码。

## 使用方法

选择匹配场景的 Prompt，阅读说明，替换正文内的 `{{占位符}}` 后复制到目标工具。仅提供任务所需且已脱敏的代码与背景。根据实际反馈改进原文，使用记录放入 [examples](../examples/README.md)。

新增资产时按实际主题分类，不提前创建空目录。参见[编写指南](../docs/authoring-guide.md)与[命名约定](../docs/naming-conventions.md)。
