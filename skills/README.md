# Skills

收录需要重复使用、有稳定步骤或配套资源的工作流程。目前尚未收录 Skill，不创建占位 Skill 目录。

## 收录标准

- 明确触发场景、输入、执行步骤、边界和输出。
- 有实际复用需求；单段任务指令优先放在 [prompts](../prompts/README.md)。
- 配套资源应服务于流程，不包含密钥、私人信息或未经验证的效果承诺。

## 结构与使用

一个 Skill 通常采用独立目录，以 `SKILL.md` 为入口，按需包含 `scripts/`、`references/`、`assets/`。没有内容时不创建这些子目录。元数据、安装位置、调用方式和权限等具体约定以目标工具为准。

使用前阅读完整入口说明和所需资源，核实目标工具支持情况、脚本行为与依赖，再按对应工具说明安装或调用。不要仅因存在脚本就执行它。

新增 Skill 后在此添加真实入口链接，并记录适用工具、输入要求与必要验证。参见[编写指南](../docs/authoring-guide.md)。
