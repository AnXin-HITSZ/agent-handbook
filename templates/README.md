# 项目级指令模板

收录可供其他项目复制和编辑的长期协作约定。模板应包含必要背景、导航、命令、验证要求和协作方式，保持简洁，不预设技术栈或虚构命令。

## 已有模板

- [通用 AGENTS.md](agents/general/AGENTS.md)
- [通用 CLAUDE.md](claude/general/CLAUDE.md)

两份模板分别可独立使用，不依赖另一份必然被读取。它们是资产内容，不是本仓库的全局规则。

## 使用方法

1. 查看目标工具关于指令文件名称、放置位置和作用范围的说明，选择适用模板。
2. 将模板复制到目标项目；如果已有同名文件，先阅读并合并必要内容，不直接覆盖。
3. 替换全部 `{{占位符}}`，核实路径和命令，删除无关项及模板编辑提示。未提供某项命令时明确写“未配置”并说明替代验证方式。
4. 结合项目实际使用检查是否存在冲突或过时要求，再持续修订。若同时采用多份指令文件，保持共同约定一致。

参见[命名约定](../docs/naming-conventions.md)与[编写指南](../docs/authoring-guide.md)。
